yt2abs

Extension settings

The extension sends YouTube videos to your yt2abs server, which downloads them and adds them as podcast episodes in Audiobookshelf.

Address where yt2abs runs (same host as Audiobookshelf), without a trailing slash. For LAN: http://192.168.1.10:13381.

yt2abs runs without authentication on your LAN, so only the address is needed. Nothing secret is stored in the browser.

How it works
Button
active on /watch and /shorts; badge ✓ = episode already in ABS
Shortcut
Alt+Shift+Y — send the current video
Menu
“Send to ABS” on a thumbnail or link (without opening the video)
Keep
“Keep forever” sets retention_override=0, so retention will not delete the episode
